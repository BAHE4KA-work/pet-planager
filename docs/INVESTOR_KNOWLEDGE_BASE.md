## Executive Summary (Краткая выжимка)

**PLANAGER** — это высокопроизводительная AI-native платформа для архитекторов систем, Lead Software Engineers и Product-менеджеров. Платформа трансформирует хаотичные текстовые требования и документацию в структурированный графический граф компонентов и код предметной области в формате **.pgr (Plan Graph Representation)**.

В отличие от традиционных инструментов рисования диаграмм (Miro, Draw.io) и текстовых редакторов (Notion, Confluence), **PLANAGER** сочетает строгость кода, реактивный интерактивный Canvas, встроенный Git-контроль версий и проактивного ИИ-ассистента, выявляющего логические противоречия на ранних этапах проектирования.

## 1. Проблематика рынка и Решение (Market Problem & Solution)

### Проблема ($B+ потери индустрии)
* **Архитектурная рассинхронизация:** Архитектура в Figma/Miro устаревает через неделю после написания кода.
* **Дорогие ошибки проектирования:** Обнаружение логических конфликтов (например, несовместимость классов или отсутствующие зависимости) на этапе разработки стоит в 10–50 раз дороже, чем на этапе планирования.
* **Отсутствие единого истока правды (Single Source of Truth):** Документация оторвана от описания моделей данных и связей между системами.

### Решение PLANAGER
Платформа использует универсальный язык описания архитектуры **.pgr**, поддерживающий мгновенный двусторонний парсинг между строгим кодом, наглядной визуальной базой знаний и интерактивным графом элементов Canvas.

## 2. Ключевые Модули и Функциональность

### 2.1. Интерактивная База Знаний и Двусторонний PGR-Редактор
* **Строгая DSL-структура (.pgr):** Декларативное описание систем (`sys_`), классов (`cls_`), объектов (`obj_`), компонентов (`cmp_`), процессов (`proc_`) и идей (`idea_`).
* **Два режима работы:**
  * *Structured View:* Валидированная форма редактирования свойств элементов с наследованием полей и автоматическим автодополнением.
  * *Raw PGR Code Editor:* Полноценный моноширинный редактор кода с подсветкой синтаксиса, фильтрацией по диапазону строк и мгновенной валидацией AST-дерева.
* **Файловая структура и навигация:** Поддержка папочной иерархии, быстрого поиска, изоляции контекста по типам элементов и фазам MVP.

### 2.2. Re-Engineered Interactive Canvas (Визуальный Холст)
* **Obsidian/Miro-style Canvas:** Графовое представление архитектуры с аппаратным ускорением, поддержкой панорамирования и бесконечного зума.
* **Смарт-позиционирование и направляющие:**
  * Умное прилипание к сетке (Grid Snapping) и динамические линии выравнивания (Alignment Guides) по вертикали и горизонтали.
  * Защита от "липких" узлов: физика перетаскивания оптимизирована под работу с мышью и тачпадом без застревания курсора.
* **Система связей (Edges):** Поддержка архитектурных типов связей: `contains`, `extends`, `has`, `instance_of`, `uses`, `notes` с визуальной цветовой кодировкой и маркерами направлений.
* **Групповые операции и Multi-Selection AI Context:** Выделение нескольких узлов через `Ctrl/Cmd + ЛКМ` для формирования изоляционного контекста для ИИ-анализа.
* **Умная отмена действий (Ctrl+Z Undo/Redo):** Пошаговая отмена индивидуальных и групповых перемещений узлов, а также межфайловых переносов.

### 2.3. Proactive AI Assistant & Multi-Agent Architecture
* **Центральный ИИ-Хаб:** Визуальное меню выбора специализированных ассистентов с контекстными иконками Lucide:
  1. **Детектор противоречий (Contradictions):** Автоматический сканер графа и PGR-кода. Находит логические конфликты и некорректные связи. Позволяет применить патч исправления в один клик или открыть модальное окно разбора конфликта прямо на Canvas.
  2. **Генератор архитектурных предложений (Proposals):** Формирует рекомендательные паттерны улучшения системы. При отклонении автоматически создаёт Идею-образ с атрибутами `alt_to` и `alt_reason`.
  3. **Проблемное интервью (Interview):** Интерактивный опросник для заполнения "слепых зон" в архитектуре.
  4. **Преобразование элементов (Transformation):** Автоматический разворот простых идей в многоуровневые каркасы по шаблонам:
     * *System Pack* (Система + Компонент + Класс)
     * *Class Hierarchy* (Класс + Элементы instance_of)
     * *Process Chain* (Пошаговые функции)
* **Радиальное контекстное меню (Radial AI Menu):** Контекстное колесо вокруг узла на Холсте для мгновенного вызова ИИ-операций без отрыва от работы.

### 2.4. Встроенное Git-Версионирование
* **Локальный Git-Движок:** Поддержка работы с ветками (по умолчанию `main`), фиксации коммитов и снимков состояния проекта (Snapshots).
* **Визуальный Diff-Спектр (.pgr diff):** Построчный просмотр добавлений (`+`) и удалений (`-`) в коде архитектуры между коммитами.
* **Счётчик незафиксированных изменений:** Прозрачный статус-бар с индикацией изменённых объектов.

### 2.5. Мониторинг API Ключей и Искусственные Лимиты (Quota & Safeguards)
* **Искусственные лимиты (Artificial Rate Limits):** Гибкая настройка порогов потребления для предотвращения перерасхода средств:
  * **RPM** (Requests Per Minute) — лимит запросов в минуту.
  * **RPD** (Requests Per Day) — суточный лимит запросов.
  * **TPM** (Tokens Per Day / Minute) — лимит токенов.
  * **TT** (Total Tokens) — тотальный накопительный лимит токенов с функцией **ручного сброса**.
* **Визуальная аналитика:**
  * Интерактивный гистограммный график объема запросов и токенов по часам.
  * Детализированная таблица истории запросов (время, действие, модель, prompt/completion токены, latency ms, статус HTTP 200/429/500).
  * Встроенный симулятор нагрузки для стресс-тестирования системной защиты.

### 2.6. Enterprise Design System & UX Discipline
* **System Dark Theme:** Глубокая индустриальная тёмная тема (`#0C0C0E`) по умолчанию с контекстными цветами положительных и отрицательных действий.
* **Context Shimmer Buttons:** Мягкая переливающаяся подсветка ИИ-кнопок оттенками контекстного цвета.
* **Focus Mode Discipline:** Полная адаптивность, отсутствие лишних логов и служебного шума в интерфейсе пользователя.
